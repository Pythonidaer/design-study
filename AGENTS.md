# Design Study

This is Pythonidaer/design-study, a GitHub Pages site. Source curriculum and HTML/SVG generation live in build.py; shared CSS and behavior live in dist/assets/. Rebuild and run verify.py after changes.

Preserve all 32 studies and the five sections within each. Label original study illustrations separately from historical images. Dates are contextual ranges, not exclusive invention claims. Do not turn mood labels into alleged historical movements.

Preserve the user-requested 2001 Apple-inspired silver desktop tabs, striped texture, inset controls, and blue selected state. Do not copy the Apple logo or its original graphic assets. Keep pages readable and responsive. No emojis, Unicode arrow substitutes, promotional filler, or unnecessary floating UI.

Main navigation uses real links; chapter navigation supports URL hashes, browser back/forward, and no-JavaScript reading. Maintain keyboard focus, reduced-motion behavior, the responsive menu, and clearly labeled external references.

Read WEBSITE_DESIGN_BASELINE.md and DESIGN_DECISIONS.md before design changes. The source repository and user-requested hosting destination are authoritative; do not create a separate Sites deployment for this project.
